# KO 衍生品定价

本项目完成 MFE5130 课程项目的 d、e 两项任务，
以可口可乐股票（KO）为标的，使用前向二叉树计算衍生品 X 的价格。

## 研究目标

d 项：改变合约参数，分别计算欧式底层期权和美式底层期权对应的 X 价格。

e 项：保持合约参数不变，增加树的步数，研究价格的数值收敛。

## 产品结构

底层期权 V1 的行权收益为：

min(H, max(S^(3/2) - K, 0))

衍生品 X 在 T 到期，底层期权在 T+C 到期。
X 的支付取决于两份门槛分别为 K2、K3 的底层期权在 T 时的价值。

欧式或美式的行权方式适用于底层期权 V1。
X 按题目规定在 T 支付。

## 开发环境

使用 Python，依赖在 pyproject.toml 中统一声明：

- numpy：数组运算与树模型计算。
- pandas：读取数据与整理结果。
- openpyxl：支持读取 Excel。
- matplotlib：绘制结果与收敛曲线。

在项目根目录的 PowerShell 终端中执行：

```powershell
# 首次配置时创建项目专用的 Python 虚拟环境
python -m venv .venv

# 使用虚拟环境中的 Python，根据项目配置安装依赖
.\.venv\Scripts\python.exe -m pip install -e .
```

虚拟环境创建成功后，无需每次重新创建。
